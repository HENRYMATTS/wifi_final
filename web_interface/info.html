Disclaimer

This is a 2.4Ghz wifi penetration testing device.
This device is a proof of concept for testing and educational purposes.

Use it only against your own networks and devices!
Use it only against Networks you have been authorised to test!

It uses valid Wi-Fi frames described in the IEEE 802.11 standard and does not block or disrupt any frequencies.

Please don't refer to this device as "jammer", as it undermines the real purpose of this device!
If you do, it only proves that you didn't understand anything of what this device stands for.
